## What it does

`main.ts` (Node 22) writes one original roast line — at most 200
characters, roasting a gadget used every day — to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
The output is deterministic: the same bytes on every run.

## Run

```sh
node main.ts
```
